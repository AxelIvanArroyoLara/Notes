## ¿Qué es el aprendizaje automático?

El aprendizaje automático es un subcampo de la inteligencia artificial que permite a las computadoras aprender sin ser programadas de manera explícita para cada tarea. En lugar de depender únicamente de instrucciones fijas escritas paso a paso, estos sistemas utilizan algoritmos capaces de identificar patrones en los datos y, a partir de ellos, realizar predicciones, clasificaciones o decisiones.

La inteligencia artificial, en un sentido amplio, se entiende como la capacidad de una máquina para imitar comportamientos humanos inteligentes. Esto incluye tareas como reconocer escenas visuales, comprender texto escrito en lenguaje natural o ejecutar acciones en el mundo físico. Dentro de ese marco general, el aprendizaje automático constituye una disciplina especializada cuyo propósito es que las computadoras mejoren su desempeño al analizar grandes cantidades de información.

La idea central consiste en que, mediante algoritmos, una computadora puede detectar regularidades en los datos y usarlas para anticipar resultados futuros. Por ello, también se relaciona con el análisis predictivo. Gracias a este enfoque, las máquinas pueden ejecutar tareas específicas de forma autónoma, sin requerir que cada posible caso sea programado manualmente.

## Aprendizaje supervisado

### Definición y funcionamiento

El aprendizaje supervisado se basa en datos etiquetados. Esto significa que cada ejemplo de entrenamiento incluye tanto la entrada como la salida deseada. El sistema aprende a partir de esos pares entrada-salida, de modo que puede inferir una regla general que relacione ambas partes y después aplicarla a datos nuevos.

En este enfoque existe, conceptualmente, una especie de “maestro”, ya que al ordenador se le presentan ejemplos correctos previamente preparados. El objetivo del algoritmo consiste en aprender la relación entre las entradas y sus respuestas esperadas, para luego poder generar predicciones sobre ejemplos que no ha visto antes.

Desde una perspectiva matemática, los algoritmos de aprendizaje supervisado construyen un modelo a partir de un conjunto de datos de entrenamiento. Cada ejemplo suele representarse mediante un vector de características, y el conjunto completo puede organizarse como una matriz. A través de la optimización de una función objetivo, el algoritmo ajusta sus parámetros hasta encontrar una función que prediga adecuadamente la salida correspondiente a nuevas entradas. Cuando ese desempeño mejora con el tiempo, se considera que el sistema ha aprendido la tarea.

![[Pasted image 20260404184232.png]]
### Ventajas

El aprendizaje supervisado puede alcanzar una precisión muy alta cuando se dispone de datos suficientes y correctamente etiquetados. Esta es una de sus principales fortalezas, ya que el modelo aprende sobre ejemplos cuya respuesta correcta ya se conoce.

Además, algunos modelos supervisados, como la regresión lineal, resultan fáciles de interpretar. Esto permite comprender con mayor claridad por qué el sistema produce cierto resultado, lo cual es muy valioso en contextos donde no solo importa acertar, sino también justificar la decisión.

Otra ventaja importante es su versatilidad. Puede adaptarse a problemas muy distintos, desde la predicción de valores numéricos hasta la clasificación de elementos en categorías.

### Desventajas

Una desventaja central es que requiere una gran cantidad de datos preetiquetados. La recolección y etiquetado de esta información puede ser costosa, lenta y demandante en términos de trabajo humano.

También existe el riesgo de sobreajuste. Esto ocurre cuando el modelo aprende demasiado bien los datos de entrenamiento, incluyendo patrones específicos o ruido que no se repiten en nuevos datos. Como consecuencia, el sistema puede fallar al generalizar.

Su rendimiento, además, depende fuertemente de la calidad y relevancia de los datos utilizados para entrenarlo. Si los datos contienen errores, sesgos o poca representatividad, el modelo tenderá a heredar esas limitaciones.

### Aplicaciones

El aprendizaje supervisado se utiliza en diagnóstico médico para predecir enfermedades a partir de datos del paciente. En este caso, el sistema aprende de registros clínicos previos y luego estima la posible condición de un nuevo paciente.

También se aplica en reconocimiento de voz y de texto, donde transforma señales de audio o secuencias escritas en comandos o texto procesable.

Otra aplicación destacada aparece en los sistemas de recomendación, como los utilizados por plataformas del estilo de Netflix o Amazon, donde se generan sugerencias personalizadas según patrones observados en usuarios y contenidos.

Asimismo, tiene uso en detección de fraude, especialmente en el ámbito financiero, para identificar transacciones sospechosas en tiempo real.

## Aprendizaje no supervisado

### Definición y funcionamiento

El aprendizaje no supervisado trabaja con datos sin etiquetar. En este caso no se le indica al sistema cuál es la respuesta correcta, sino que el algoritmo debe explorar por sí mismo la estructura de la información para descubrir regularidades, agrupamientos o tendencias.

Este enfoque resulta valioso porque puede encontrar patrones que ni siquiera se estaban buscando de forma explícita. En lugar de comenzar con categorías o respuestas predeterminadas, el algoritmo enfrenta un conjunto de datos aparentemente caótico e intenta organizarlos de manera significativa.

En el ámbito del marketing, por ejemplo, estas técnicas se emplean para analizar grandes cantidades de datos obtenidos de redes sociales. A partir de ello, es posible detectar patrones de comportamiento y diseñar campañas publicitarias altamente segmentadas.

Una técnica representativa dentro de este tipo de aprendizaje es el análisis de clústeres. Su propósito consiste en agrupar observaciones en subconjuntos tales que los elementos dentro de un mismo grupo sean similares entre sí, mientras que los elementos de grupos distintos sean diferentes. Para lograrlo, se utilizan métricas de similitud, criterios de compacidad interna, separación entre grupos y también enfoques basados en densidad o conectividad de grafos.

![[Pasted image 20260404184625.png]]
### Ventajas

Una ventaja importante es que no requiere datos etiquetados, lo cual ahorra tiempo y recursos.

También permite descubrir estructuras y relaciones ocultas dentro de los datos, lo que lo vuelve especialmente útil cuando todavía no se conoce bien el comportamiento del problema que se desea estudiar.

Además, resulta muy útil para tareas de preprocesamiento y exploración de datos, ya que ayuda a comprender la distribución, los patrones y la organización interna de la información antes de aplicar otros métodos.

### Desventajas

Los resultados suelen ser más difíciles de interpretar que en el aprendizaje supervisado. Como no existe una verdad de referencia conocida, puede ser menos evidente qué significa exactamente cada agrupación o patrón encontrado.

También hay menor control sobre los resultados. Esto implica que el algoritmo puede detectar estructuras que, aunque matemáticamente válidas, no resulten útiles o relevantes para el problema práctico.

Evaluar la calidad del modelo también puede ser complicado, precisamente porque no se cuenta con una respuesta correcta conocida contra la cual comparar.

### Aplicaciones

Entre sus aplicaciones más comunes se encuentra la segmentación de mercado, donde se agrupa a los clientes según su comportamiento de compra.

También se utiliza en detección de anomalías para identificar comportamientos inusuales en datos financieros o de seguridad.

Otra aplicación relevante es la compresión de datos, en la que se reduce el tamaño de la información conservando los elementos esenciales.

## Aprendizaje por refuerzo

### Definición y funcionamiento

El aprendizaje por refuerzo se centra en cómo deben actuar los agentes de software dentro de un entorno con el objetivo de maximizar una recompensa acumulativa. A diferencia del aprendizaje supervisado, aquí no se parte de pares entrada-salida etiquetados, sino de interacciones sucesivas entre un agente y su entorno.

En este enfoque, el entorno suele representarse como un proceso de decisión de Markov, también abreviado como PDM. Muchos algoritmos de aprendizaje por refuerzo utilizan técnicas de programación dinámica, aunque generalmente no se asume el conocimiento exacto del modelo matemático del entorno. Esto es especialmente útil cuando obtener un modelo preciso no resulta factible.

El principio general consiste en que el agente realiza acciones, observa sus consecuencias y recibe recompensas o penalizaciones. Con el tiempo, aprende una política de acción que le permite maximizar el beneficio total acumulado.

![[Pasted image 20260404184706.png]]

### Aplicaciones

Este tipo de aprendizaje se emplea en vehículos autónomos, donde el sistema debe aprender a tomar decisiones apropiadas en un entorno cambiante.

También se utiliza para aprender a jugar contra un oponente humano, como ocurre en videojuegos o sistemas de estrategia.

## Proceso de aprendizaje automático

### 1. Recopilación y preprocesamiento de datos

El primer paso consiste en recopilar los datos relevantes que se usarán para entrenar el modelo. Esta información puede provenir de múltiples fuentes, como bases de datos, sensores, archivos de registro o API.

El resultado inicial es un conjunto de datos brutos que servirá como base para entrenar y evaluar el sistema. Sin embargo, no basta con reunir información: los datos deben ser de buena calidad y representar adecuadamente el problema que se desea resolver. De lo contrario, incluso un algoritmo avanzado producirá resultados deficientes.

![[Pasted image 20260404184936.png]]
### 2. División de datos

Una vez que se dispone del conjunto completo, este se divide en tres subconjuntos:

#### Datos de entrenamiento

Representan aproximadamente entre el 60% y el 70% del total. Se utilizan para entrenar el modelo, es decir, para ajustar sus parámetros internos.

#### Datos de validación

Suelen ocupar entre el 15% y el 20%. Se emplean para ajustar hiperparámetros y ayudar a prevenir el sobreajuste.

#### Datos de prueba

También abarcan normalmente entre el 15% y el 20%. Su función es evaluar el rendimiento final del modelo y medir qué tan bien generaliza ante datos nuevos.

![[Pasted image 20260404184924.png]]
### 3. Formación de modelos

En esta etapa, el modelo se entrena utilizando los datos de entrenamiento. El sistema aprende de esos datos con el propósito de minimizar el error y mejorar la precisión de sus predicciones.

Para llevar a cabo esta fase se necesita el conjunto de entrenamiento, el algoritmo seleccionado y los hiperparámetros correspondientes. Como resultado se obtiene un modelo entrenado, cuyos parámetros internos han sido ajustados para optimizar su comportamiento frente a los datos utilizados.

![[Pasted image 20260404185051.png]]

### 4. Evaluación y validación

Después del entrenamiento, el rendimiento del modelo se analiza utilizando los datos de validación y de prueba. Durante esta fase, también pueden ajustarse los hiperparámetros en función de los resultados observados.

A partir de esta evaluación se obtienen distintas métricas de rendimiento que permiten juzgar la calidad del modelo. Entre las métricas señaladas se encuentran las siguientes:

#### Exactitud

Mide la proporción total de predicciones correctas respecto del total de casos evaluados.

#### Precisión

Indica qué proporción de las predicciones positivas realizadas por el modelo fue realmente correcta.

#### Recall

También llamado exhaustividad, mide la proporción de casos positivos reales que el modelo logró identificar.

#### F1-Score

Es una medida que combina precisión y recall, ofreciendo un equilibrio entre ambas.

#### Matriz de confusión

Permite visualizar el número de verdaderos positivos, verdaderos negativos, falsos positivos y falsos negativos.

#### Error cuadrático medio (MSE)

Se utiliza especialmente en problemas de regresión y mide el promedio de los errores al cuadrado entre los valores reales y las predicciones.

#### Área bajo la curva (AUC - ROC)

Evalúa la capacidad discriminativa de un modelo de clasificación, particularmente para distinguir entre clases.

![[Pasted image 20260404185158.png]]
### Implementación y despliegue

Una vez seleccionado el modelo final, este se implementa en un entorno de producción. Dicho entorno puede ubicarse en la nube, en un servidor local o en otra infraestructura adecuada.

El sistema desplegado utiliza el modelo entrenado para procesar nuevos datos y generar predicciones en tiempo real o bajo demanda. Esta fase también puede incluir mecanismos de monitorización y actualización continua, con el fin de mantener el rendimiento del sistema y su adaptabilidad ante nuevos datos.

## Algoritmos comunes

### Regresión lineal

#### Definición

La regresión lineal es una técnica de aprendizaje automático utilizada para modelar la relación entre una variable dependiente, también llamada respuesta, y una o más variables independientes, conocidas como predictores.

Su objetivo es encontrar la mejor línea recta posible, en el caso de una sola variable independiente, de manera que se minimice la suma de los errores cuadráticos entre las predicciones y los valores reales. En otras palabras, busca una relación lineal que explique lo mejor posible el comportamiento de los datos observados.

![[Pasted image 20260404185559.png]]

#### Ventajas

La regresión lineal es fácil de entender e implementar. Además, sus coeficientes suelen ser interpretables, lo que permite comprender la influencia de cada variable sobre la salida.

También es computacionalmente eficiente para problemas sencillos, por lo que constituye una herramienta básica y muy útil en muchos contextos.

#### Desventajas

Solo captura relaciones lineales, por lo que resulta insuficiente cuando el fenómeno real sigue comportamientos no lineales.

Puede verse afectada por valores atípicos, es decir, datos que se desvían significativamente del resto de las observaciones.

Tampoco modela bien relaciones no lineales, lo que limita su aplicabilidad en problemas más complejos.

#### Casos de uso

##### Caso 1: Predicción de precios de vivienda

Se utiliza para estimar el precio de una casa a partir de características como superficie, número de habitaciones y ubicación. Para ello se entrenan modelos con datos históricos de casas vendidas anteriormente y luego se predice el valor de una nueva vivienda a partir de sus atributos.

##### Caso 2: Previsión de ventas

Puede emplearse para predecir ventas futuras de un producto usando datos históricos, gastos publicitarios y factores estacionales. El resultado ayuda a planificar inventario y estrategias de marketing.

##### Caso 3: Análisis de riesgos financieros

Sirve para evaluar el riesgo de impago de un préstamo considerando historial crediticio, ingresos, deudas y otras características financieras del solicitante. De este modo, apoya la toma de decisiones en instituciones financieras.

## Árboles de decisión

### Definición

Un árbol de decisión es un modelo predictivo que puede emplearse tanto para clasificación como para regresión. Representa decisiones y consecuencias posibles mediante una estructura arbórea.

Cada nodo interno plantea una pregunta basada en una característica, cada rama corresponde a una posible respuesta y cada hoja representa un resultado final o una clase. Esta estructura permite seguir un camino de decisiones hasta obtener una predicción.

![[Pasted image 20260404185634.png]]
### Ventajas

Una de sus grandes fortalezas es la interpretabilidad, ya que son fáciles de entender y visualizar.

Además, no requieren escalado de características, por lo que no necesitan normalización previa.

También pueden manejar tanto datos categóricos como numéricos, lo que les da gran flexibilidad.

### Desventajas

DPueden sobreajustarse a los datos de entrenamiento, especialmente cuando el árbol crece demasiado.

También presentan inestabilidad: pequeños cambios en los datos pueden producir árboles completamente distintos.

Su precisión puede ser limitada frente a modelos más complejos, salvo que se optimicen adecuadamente.

### Casos de uso

#### Caso 1: Diagnóstico médico

Permiten clasificar pacientes en distintas categorías de enfermedades con base en síntomas y datos médicos, ayudando a los médicos a emitir diagnósticos más rápidos y precisos.

#### Caso 2: Segmentación de clientes en marketing

Sirven para dividir una base de clientes en grupos diferenciados según características demográficas y comportamientos de compra, permitiendo campañas más específicas y eficaces.

#### Caso 3: Evaluación del riesgo crediticio

Se emplean para estimar la probabilidad de incumplimiento de pago en solicitantes de préstamo, usando información financiera e historial crediticio.

## Bosque aleatorio

### Definición

El bosque aleatorio es un algoritmo de aprendizaje supervisado basado en la combinación de múltiples árboles de decisión. Pertenece a los métodos de conjunto, es decir, técnicas que integran varios modelos con el fin de mejorar el rendimiento global.

Su construcción consiste en generar varios árboles a partir de diferentes subconjuntos de los datos de entrenamiento, tomados con reemplazo. Este procedimiento recibe el nombre de agregación bootstrap o bagging.

Cada árbol produce una predicción independiente. Luego, la predicción final se obtiene de la siguiente manera:

#### En clasificación

Se utiliza votación mayoritaria, de modo que la clase final es aquella que recibe más votos entre todos los árboles.

#### En regresión

Se promedian las predicciones de todos los árboles para generar el resultado final.

![[Pasted image 20260404185845.png]]
### Ventajas

Reduce el riesgo de sobreajuste gracias a la combinación de múltiples modelos.

Es muy robusto frente a datos ruidosos o incompletos.

Funciona bien en problemas no lineales y con datos de alta dimensionalidad.

Además, maneja simultáneamente datos categóricos y numéricos.

### Desventajas

Puede ser computacionalmente costoso cuando se utilizan demasiados árboles.

También es difícil de interpretar, ya que al combinar muchos árboles se comporta más como una caja negra.

## Naive Bayes

### Definición

El clasificador Naive Bayes se fundamenta en el teorema de Bayes y asume que las variables de entrada son independientes entre sí. De ahí proviene el término “naive” o “ingenuo”, ya que en muchos problemas reales esa independencia no se cumple estrictamente.

La fórmula general puede expresarse como:

$$  
P(C \mid X) = \frac{P(X \mid C),P(C)}{P(X)}  
$$

donde $C$ representa la clase y $X$ el conjunto de características.

![[Pasted image 20260404190027.png]]
### Funcionamiento

El modelo calcula la probabilidad de que una observación pertenezca a una clase dada a partir de sus características.

Durante el entrenamiento, se estima la probabilidad previa de cada clase usando los datos de entrenamiento y también la probabilidad condicional de cada característica dado cada clase.

Después, cuando se recibe una nueva entrada, se calcula la probabilidad posterior de pertenecer a cada clase y se asigna la clase con la probabilidad más alta.

Aunque el supuesto de independencia rara vez se cumple por completo, el algoritmo sigue siendo muy eficaz en muchos escenarios prácticos.

### Ventajas

Es muy rápido y eficiente, incluso con grandes conjuntos de datos.

Requiere pocos datos para el entrenamiento.

Funciona bien con datos categóricos y de texto, como en la clasificación de spam.

También es fácil de interpretar y comprender.

### Desventajas

El supuesto de independencia rara vez se cumple exactamente en la práctica.

No funciona bien cuando los datos numéricos están altamente correlacionados.

Además, puede fallar si aparece una categoría que no fue observada durante el entrenamiento.

## Support Vector Machine (SVM)

### Definición

Las máquinas de vectores de soporte, conocidas como SVM, son modelos supervisados que buscan encontrar el hiperplano que mejor separe las clases dentro del espacio de características.

La idea central es construir una frontera de decisión óptima entre clases. Cuando los datos no pueden separarse linealmente en su espacio original, se pueden usar kernels para transformarlos implícitamente a un espacio donde sí sea posible separarlos mejor.

Por ello suele hablarse de SVM lineal y SVM con kernel.

![[Pasted image 20260404190201.png]]
### Ventajas

Son muy eficaces para datos de alta dimensionalidad.

Funcionan bien cuando existe una separación clara entre clases.

El uso de kernels permite abordar problemas no lineales.

Además, con la regularización adecuada, son resistentes al sobreajuste.

### Desventajas

Pueden ser lentas con conjuntos de datos grandes.

Son difíciles de interpretar, especialmente cuando se emplean núcleos complejos.

También puede resultar complicado ajustar correctamente sus parámetros, como el tipo de kernel.
