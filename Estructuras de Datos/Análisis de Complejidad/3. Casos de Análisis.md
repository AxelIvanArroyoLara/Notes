
## Introducción

Los **casos de análisis** permiten determinar el número de operaciones que serán realizadas por un algoritmo dadas ciertas condiciones. En este caso, se toma un caso pésimo, uno promedio y el mejor de todos.
### Peor caso:

Este es el caso más utilizado para el análisis de algoritmos. Aquí, se calcula el umbral mayor del tiempo de ejecución de un algoritmo; esto, para conocer el número máximo de operaciones que podrían ser ejecutadas.

### Mejor caso:

Si bien casi no es utilizado, este permite visualizar el umbral menor para el tiempo de ejecución. Las condiciones en este entorno son las propicias para efectuar el menor número de operaciones posibles. Por ejemplo, en búsqueda lineal, el mejor caso ocurre cuando $x$ se encuentra presente en el primer índice. 

El número de operaciones en el mejor caso siempre es constante; es decir, no dependiente de $n$, por lo que se toma directamente del tamaño de la entrada.

### Caso promedio:

Aquí se toman todas las entradas posibles y posteriormente se calcula el tiempo de cómputo total para todas, obteniendo el promedio entre estas. 

---
## Uso del Peor Caso

Los casos de utilizan de acuerdo con la frecuencia con la que aparecen en entornos de ejecución real. Por ejemplo, el caso promedio no es sencillo de ver en aplicaciones prácticas; esto, ya que al considerar cada entrada, sus frecuencias y tiempo pueden no ser posibles en muchos escenarios.

Por su parte, el mejor caso es un análisis de un valor limitado: conocer el umbral inferior brinda poca información acerca del peor caso, que podría mantener un tiempo extremadamente largo.

Por último, el peor caso es más sencillo de ver que el promedio, y al estar basado en el límite superior, otorga información útil para analizar las consecuencias reales de su elección.

## Ejemplos con su Complejidad

Para un caso de búsqueda lineal:

```
#include <stdio.h>
#include <stdbool.h>

// Linearly search target in arr.
// If target is present, return the index;
// otherwise, return -1
int search(int arr[], int size, int x) {
    for (int i = 0; i < size; i++) {
        if (arr[i] == x)
            return i;
    }
    return -1;
}

int main() {
    int arr[] = {1, 10, 30, 15};
    int size = sizeof(arr) / sizeof(arr[0]);
    int x = 30;
    printf("%d", search(arr, size, x));
    return 0;
}

// Output

2

```

- **Mejor caso:** El tiempo constante no es respectivo al tamaño de la entrada. Esto tendrá lugar en el caso de que el elemento que se busca se encuentre en el primer índice del arreglo; por lo tanto, la lista de comparaciones será de tan solo $1$
- **Caso promedio:** Es tiempo lineal, y tendrá lugar dado el caso de que el elemento a ser buscado se encuentre en el índice intermedio.
- **Peor caso:** El elemento buscado no está contenido en la lista.
