La **notación theta** ($\theta$) es una que provee umbrales exactos de tiempo o complejidad espacial desde los límites inferiores y superiores. En contraste con Big $O$ o Big $\Omega$, esta notación brinda más información para casos en donde el límite exacto está disponible y debería preferirse. Por ejemplo, un algoritmo como *Merge Sort* cuyo tiempo siempre es $nLog(n)$, lo que se ve replicado en $\theta(nLog(n))$.

Sean $g$ y $f$ funciones del conjunto de los números naturales hacia sí mismos. Se dice que la función $f$ es $Θ(g)$ si existen constantes $c1, c2 > 0$ y un número natural $n0$, tales que:

$$
c_1 \cdot g(n) \leq f(n) \leq c_2 \cdot g(n)
$$

para todo $n \geq n_0$.

$$
\Theta(g(n)) = \{f(n): \text{existen constantes positivas } c_1, c_2 \text{ y } n_0 \text{ tales que } 0 \leq c_1 \cdot g(n) \leq f(n) \leq c_2 \cdot g(n) \text{ para todo } n \geq n_0\}
$$

**Nota:** $\Theta(g)$ es un conjunto.

La definición anterior significa que, si $f(n)$ es theta de $g(n)$, entonces el valor de $f(n)$ siempre está entre $c_1 \cdot g(n)$ y $c_2 \cdot g(n)$ para valores grandes de $n$, es decir, cuando $n \geq n_0$.

La definición de theta también requiere que $f(n)$ sea no negativa para valores de $n$ mayores que $n_0$.

En otras palabras, esta notación determina los límites inferior y superior de acuerdo con el uso de dos constantes. 

Por ejemplo, considérese un ejemplo en el que una llave existe dentro de un arreglo: la idea es atravesarlo y revisar si cada uno de los elementos es igual al valor buscado o no:

```
bool linearSearch(int a[], int n, int key)  
{  
    for (int i = 0; i < n; i++) {  
        if (a[i] == key)  
            return true;  
    }  
    return false;  
}
```

En una **búsqueda lineal**, el algoritmo revisa los elementos uno por uno hasta encontrar la clave.  
  
Si el arreglo tiene $n$ elementos, la clave puede estar en:  
  
- La posición 1  
- La posición 2  
- ...  
- La posición $n$  
- O no estar en el arreglo  
  
Por eso hay $n + 1$ casos posibles.  
  
Si asumimos que todos los casos son igual de probables, calculamos el promedio:  
  
$\text{Tiempo promedio} = \frac{\sum_{i=1}^{n+1} \Theta(i)}{n+1}$  
  
La suma $1 + 2 + 3 + ... + (n+1)$ es:  
  
$\frac{(n+1)(n+2)}{2}$  
  
Entonces:  
  
$\frac{\Theta((n+1)(n+2)/2)}{n+1}$  
  
Al simplificar:  
  
$\Theta(1 + n/2)$  
  
Y como en notación asintótica se eliminan constantes:  
  
$\Theta(n)$  
  
**Conclusión:**  
El caso promedio de la búsqueda lineal es $\Theta(n)$, porque en promedio el número de comparaciones crece linealmente con el tamaño del arreglo.
