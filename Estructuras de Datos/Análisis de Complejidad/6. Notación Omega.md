La notación Omega ($\Omega$) se basa en hallar el mejor caso para un algoritmo dado; esto, al brindar un límite igual o menor para el tiempo tomado por un algoritmo en términos del tamaño de la entrada. 

Dadas dos funciones $g(n)$ y $f(n)$, se dice que $f(n)=\Omega(g(n))$ si existen constantes $c>0$ y $n_0$ tal que $f(n)>=c*g(n)$ para todos los $n>=n_0$. Es decir, la función es de complejidad omega siempre y cuando esta crezca más rápidamente que la expresión $c*g(n)$ para todos los valores de $n >=n_0$ en donde $c$ y $n_0$ son constantes.

Esta notación se utiliza cuando se desea indicar que el algoritmo tomará *al menos* cierta cantidad de tiempo en ocurrir. Por definición, para cualquier algoritmo se tiene una complejidad de $\Omega(1)$, al garantizar el umbral más bajo; sin embargo, se debe hallar el más cercano posible a la función.

Para hallar la notación, primero se debe dividir el algoritmo en segmentos, de los cuales cada uno debe tener una complejidad definida. Con ellos, se halla entonces el número de operaciones realizadas para cada sección en términos de sus entradas, asumiendo que cada una toma el menor tiempo posible. Ahora, se proceden a sumar las complejidades y se simplifican en la forma $f(n)$. Por último, se eliminan todas las constantes y se selecciona el término de menor orden, que es siempre menor a $f(n)$. Por ejemplo:

```
// C++ program for the above approach
#include <bits/stdc++.h>
using namespace std;

// Function to print all possible pairs
int print(int a[], int n)
{
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (i != j)
                cout << a[i] << " " << a[j] << "\n";
        }
    }
}

// Driver Code
int main()
{
    int a[] = { 1, 2, 3 };
    int n = sizeof(a) / sizeof(a[0]);
    print(a, n);
    return 0;
}
```

En este ejercicio, se asume que la impresión se ejecuta un total de $n^2$ veces. Cuando las entradas tienden a infinito, el mejor caso para este sistema puede encontrarse en $Ω(n^2)$, $Ω(log (n))$, $Ω(n)$, $Ω(1)$ o $c$ o cualquier otra función $g(n)$ menor o igual a $n^2$ veces. Sin embargo, y como se aseveró anteriormente, es mejor utilizar el umbral menor más cercano al tiempo definido.
