En C es posible crear tipos de datos propios que derivan de otros tipos de datos ya existentes. Estos permiten personalización en la base de código, mayor flexibilidad y eficiencia, y formas de generar abstracción. 

Existen cuatro tipos principales de tipos definidos por los usuarios:

- Structure
- Union
- Enum
- Typedef

### Structure:

Al no existir características orientadas a objetos como en C++, las estructuras se utilizan para efectuar ciertos tipos de encapsulamiento, fungiendo a manera de agrupamiento para distintos tipos dentro de uno mismo. Estas se definen mediante la palabra `struct`, y su tamaño es igual o mayor al tamaño total de todos sus miembros.

```
// Sintaxis base

struct strcture_name{
data_type member_name_1;
data_type member_name_2;
....
....

};

// Ejemplo 

// C Code to implement a struct
#include <stdio.h>

// Defining a structure
struct Person {
    char company[50];
    int lifespan;
};

int main()
{
    // Declaring a variable of the structure type
    struct Person person1;

    // Initializing structure members
    strcpy(person1.company, "GeeksforGeeks");
    person1.lifespan = 30;

    // Accessing and printing structure members
    printf("Name: %s\n", person1.company);
    printf("Age: %d\n", person1.lifespan);
    return 0;
}

// Output

Name: GeeksforGeeks
Age: 30

```

Esto es similar a los objetos.

### Unión:

Las **uniones** son similares a las estructuras, diferenciándose en el hecho de que los miembros de una unión se almacenan dentro de una misma dirección de memoria, lo que resulta en que solo uno de ellos contenga datos simultáneamente. El tamaño de una unión es, entonces, el tamaño del miembro de mayor tamaño, y se usa mediante `union`.

```
// Sintaxis base

**union** _union_name_ {
    datatype _member1;_
    datatype _member2;_
    ...
};

// Ejemplo

// C Code to implement Union
#include <stdio.h>

// Declaring a union
union Data {
    int i;
    float f;
    char str[20];
};

int main()
{
    // creating an instance named 'data' of union Data
    union Data data;
    data.i = 10;
    printf("Data.i: %d\n", data.i);

    data.f = 3.14;
    printf("Data.f: %f\n", data.f);

    strcpy(data.str, "GeeksforGeeks, C");
    printf("Data.str: %s\n", data.str);
    return 0;
}

```

### Enumeration:

**Enum** tiene el propósito de crear tipos de datos customizados con base en un set de enteros constantes. Declara una enumeración, haciendo el código más legible.

```
enum enum_name{const1, const2, ..., constN};
```

En donde la primera constante `const1` será asignada 0, y la segunda 1, y así continuamente en la secuencia, aunque también pueden asignarse sus valores manualmente. 

```
// C code to implement enum
#include <stdio.h>

// Declaring a enum
enum Cafes {
    Dyu_Art_Cafe,
    Tea_Villa_Cafe,
    The_Hole_in_the_Wall_Cafe,
    Cafe_Azzure,
    The_Banaglore_Cafe,
    Dialogues_Cafe,
    Cafe_Coffee_Day
};

// driver code
int main()
{
    enum Cafes today = The_Banaglore_Cafe;
    printf("Today is %d\n", today);
    return 0;
}

// Output

Today is 4

```

### Typedef:

Se utiliza para redefinir los nombres de otros tipos de dato existentes mediante `typedef`:

```
// Sintaxis base

typedef _existing_name alias_name;_

// Ejemplo

// C Code to implement Typedef
#include <stdio.h>

typedef char Company;

int main()
{
    Company* name = "GeeksforGeeks";
    printf("Best Tutorials on: %s \n", name);
    return 0;
}

// Output

Best Tutorials on: GeeksforGeeks

```
