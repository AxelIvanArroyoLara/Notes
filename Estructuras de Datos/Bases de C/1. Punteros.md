Los **punteros** son un elemento cuyo propósito reside en guardar la dirección de memoria en la que se encuentra una variable.

- Los punteros se declaran especificando su tipo y nombre, con un asterisco ( * ) antes de este último:

```
// Sintaxis general
data_type *pointer_name;

// Ejemplo
int *ptr; // Declara un puntero hacia un valor entero
 
```

En este caso, accesar al valor del puntero únicamente nos regresará la dirección que está guardada en la misma. Para obtener el valor alojado en tal dirección, se utiliza el operador * , al que se le conoce como *dereferencing operator*. Es importante destacar, entonces, que el operador se utiliza con dos objetivos: declarar una variable puntero y accesar el valor guardado en la dirección guardada en el mismo:

```
#include <stdio.h>

int main()
{

    // Normal Variable
    int var = 10;

    // Pointer Variable ptr that stores address of var
    int *ptr = &var;

    // Directly accessing ptr will give us an address
    printf("%p", ptr);

    return 0;
}

// Output

0x7fffffffe9cc

```

## Inicialización de un Puntero

Los punteros se inicializan al asignarles la dirección de una variable mediante el uso del **operador de dirección** *&*. La sintaxis requerida es la siguiente:

```

// Sintaxis base

pointer_name = &variable_name;

```

Esto se utiliza para asegurar que el puntero apunte a una dirección válida de memoria antes de usarlo. En caso de que la variable no exista o no deba ser anexada al comienzo del programa, se apunta hacia *NULL*

```
#include <stdio.h>

int main() {
    int var = 10;
    
    // Store address of var variable
    int* ptr = &var;
    
    // Dereferencing ptr to access the value
    printf("%d", *ptr);
    
    return 0;
}

// Output

10

```

## Tamaño de los Punteros

El tamaño de los punteros es directamente dependiente de la arquitectura del procesador. En sistemas de 32 bits, ocupan solo 4 bytes, mientras que en los de 64, se toman 8.

Para validar el tamaño 

``` 
#include <stdio.h>

int main() {
    int *ptr1;
    char *ptr2;
    
    // Finding size using sizeof()
    printf("%zu\n", sizeof(ptr1));
    printf("%zu", sizeof(ptr2));
    
    return 0;
}

// Output

8
8
```

## Punteros Especiales

### Puntero NULL:

Estos no apuntan a ninguna dirección de memoria y pueden ser asignados a cualquier tipo de punteros. Este tipo de punteros regularmente se utilizan para validar si se está apuntando a alguna dirección válida de memoria revisando si esta es igual a NULL.

```
#include <stdio.h>

int main() {
    // Null pointer
    int *ptr = NULL;
    
    return 0;
}
```

### Puntero Void:

El *void* se aplica a manera de tipo de dato y significa que el puntero no tiene un tipo. También se les conoce como **punteros genéricos** y pueden ser casteados a cualquier tipo de dato. 

```
#include <stdio.h>

int main() {
    // Void pointer
    void *ptr;
    
    return 0;
}
```

### Punteros Salvajes (Wild):

Estos son punteros que aún no han sido inicializados, y pueden llegar a ocasionar problemas en los programas. Si los valores son actualizados utilizando estos punteros, pueden llegar a ocasionar aborto o corrupción en los datos.

```
#include <stdio.h>

int main() {

    // Wild Pointer
    int *ptr;
    
    return 0;
}
```

## Aritmética de Punteros

La **aritmética de punteros** se refiere a aquellas operaciones que pueden ser realizadas en un puntero. Solo un número limitado de ellas pueden ser ejecutadas en estos:

- Incremento y decremento.
- Adición y sustracción de enteros.
- Sustracción dos punteros de un mismo tipo.
- Comparación y asignación de dos punteros de un mismo tipo.
- Comparación y asignación con NULL.

## Punteros Constantes

Para los **punteros constantes**, la dirección de memoria guardada es constante y no puede ser modificada una vez que se define.

```
#include <stdio.h>

int main() {
    int a = 90;
    int b = 50;

    // Creating a constant pointer
    int* const ptr = &a;
    
    // Trying to reassign it to b
    ptr = &b;

    return 0;
}

// Output

Error

```

## Puntero a Función

Un **puntero función** es un tipo de puntero que guarda la dirección de una función, permitiendo a estas últimas pasar como argumentos y ser invocadas de manera dinámica. Es sumamente útil para funciones como *callback* y programas orientados a eventos:

```
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main() {
  
    // Declare a function pointer that matches
  	// the signature of add() function
    int (*fptr)(int, int);

    // Assign address of add()
    fptr = &add;

    // Call the function via ptr
    printf("%d", fptr(10, 5));

    return 0;
    
    // Output
    
    15
}
```

## Punteros Multinivel

Esta es una capacidad que permite crear punteros que guardan la dirección de memoria en donde se encuentran otros punteros. El **doble puntero** es el más común entre ellos. 

```
#include <stdio.h>

int main() {
    int var = 10;
  
    // Pointer to int
    int *ptr1 = &var;
  
    // Pointer to pointer (double pointer)
    int **ptr2 = &ptr1;  

    // Accessing values using all three
    printf("var: %d\n", var);          
    printf("*ptr1: %d\n", *ptr1);
    printf("**ptr2: %d", **ptr2);

    return 0;
}

// Output
var: 10
*ptr1: 10
**ptr2: 10

```

Pueden existir punteros como `-***ptr3` o `-*****ptr5`

## Características de los Punteros

Estos son utilizados para efectuar locación dinámica de memoria. Cada arreglo o estructura puede ser accesada eficientemente con punteros y son utilizados para conformar estructuras de datos complejas como *listas ligadas*, *grafos*, *árboles*, etc., reduciendo el tiempo de ejecución significativamente.

Sin embargo, estos también cuentan con una serie de desventajas importantes; por ejemplo, puede existir corrupción de memoria en caso de que se les asigne un valor incorrecto, son más lentos que las variables y además pueden llevar a fugas de memoria.
