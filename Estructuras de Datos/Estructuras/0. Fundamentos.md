## Variables, Objetos y Memoria

### Variables:

Una declaración de tipo:

```
int age = 21;
```

Crea un objeto de tipo `int` con las siguientes propiedades:

```
Nombre:             age
Tipo:               int
Valor actual:       21
Tamaño:             sizeof(int)
Dirección:          una ubicación en memoria
Duración:           depende de dónde fue declarado
```

En donde:

- `age` es el nombre de la variable.
- `21` es el valor que se guarda en ese espacio de memoria.
- `int` indica cómo interpretar los bytes que conforman el contenido.

Así bien, se tiene una dirección que indica la ubicación del objeto declarado en la memoria; puede observarse mediante el operador `&`.

```
#include <stdio.h>

int main(void)
{
    int age = 21;

    printf("Valor: %d\n", age);
    printf("Direccion: %p\n", (void *)&age);

    return 0;
}
```

Mostrando como salida:

```
Valor: 21
Direccion: 0x7ffd2e6c82ac
```

Esta dirección muy seguramente variará de acuerdo con la ejecución, por lo que nunca debe asumirse que un objeto se mantendrá siempre en la misma posición.

Cabe destacar que el uso de `void *` se utiliza con `%p` de manera intencional.

### Objetos y bytes:

La memoria funge a manera de secuencia de posiciones numeradas, cada una pudiendo almacenar una pequeña cantidad de información (normalmente un solo byte).

En el caso de una variable de tipo `int`, suelen necesitarse varios bytes consecutivos (no siempre solo cuatro):

```
Dirección hipotética

0x1000   0x1001   0x1002   0x1003
+------+ +------+ +------+ +------+
| byte | | byte | | byte | | byte |
+------+ +------+ +------+ +------+
       objeto de tipo int
```

Y su tamaño suele ser fácilmente consultado mediante el método `sizeof`:

```
#include <stdio.h>

int main(void)
{
    printf("char:   %zu byte(s)\n", sizeof(char));
    printf("int:    %zu byte(s)\n", sizeof(int));
    printf("double: %zu byte(s)\n", sizeof(double));

    return 0;
}
```

En el caso de una entrevista técnica, se prefiere razonar desde una perspectiva basada en `sizeof(int)` en lugar del simple número.

### Modelo Stack y Heap:

Para comprender correctamente el funcionamiento de C, con regularidad se utiliza una división conceptual entre dos regiones distintas, tal y como se muestra en el diagrama a continuación:

```
+----------------------------------+
| Código y datos del programa      |
+----------------------------------+
| Variables globales y estáticas   |
+----------------------------------+
|                                  |
| Heap                             |
| Memoria reservada dinámicamente  |
|                                  |
+----------------------------------+
|                                  |
| Espacio disponible               |
|                                  |
+----------------------------------+
| Stack                            |
| Variables locales y llamadas     |
|                                  |
+----------------------------------+
```

Aquí se observa cómo el **stack** suele verse relacionado con:

- Variables locales.
- Parámetros de funciones.
- Información necesaria para regresar de una llamada.
- Duración automática.

Mientras que el **heap**:

- Memoria solicitada durante el tiempo de ejecución.
- Objetos cuya duración no depende directamente de una función.
- Memoria obtenida con `malloc`, `calloc` p `realloc`.
- Memoria que debe liberarse explícitamente con `free`.

### Duración automática:

Asúmase la función:

```
void example(void)
{
    int number = 10;
}
```

Aquí, el objeto `number` existe siempre y cuando el bloque se mantenga en ejecución. Su tiempo de vida termina al mismo tiempo que la del bloque en cuestión. Al ocurrir esto, cualquier puntero que tratara de mantenerse accediendo a él, deja de señalar a un objeto válido. Por ejemplo, en el caso del siguiente programa incorrecto:

```
int *create_number(void)
{
    int number = 42;
    return &number;
}
```

La función devuelve una variable local `number`; sin embargo, al esta dejar de existir al finalizar la función, el puntero recibido queda colgando:

```
Durante la función:

pointer -----> number: 42

Después de que termina:

pointer -----> región que ya no contiene un objeto válido
```

A esto se le conoce como un comportamiento indefinido.

### Duración dinámica:

Cuando se requiere que un objeto permanezca activo incluso tras la finalización de su función de origen, es posible reservar memoria de manera dinámica:

```
#include <stdlib.h>

int *create_number(void)
{
    int *number = malloc(sizeof *number);

    if (number == NULL) {
        return NULL;
    }

    *number = 42;
    return number;
}
```

Aquí, el entero deja de ser una variable local ordinaria. Si bien, el puntero local `number` sí deja de existir al finalizar la función, el bloque dinámico permanece reservado. 

Debido a la permanencia asignada a la variable en memoria, el desarrollador se hace responsable de liberarla:

```
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *number = create_number();

    if (number == NULL) {
        fprintf(stderr, "No fue posible crear el numero.\n");
        return 1;
    }

    printf("%d\n", *number);

    free(number);
    number = NULL;

    return 0;
}
```

Este es un principio al que se le conoce como **propiedad de memoria**:

	Quien recibe la propiedad de un bloque dinámico debe asegurarse de
	liberarlo cuando deje de necesitarlo.

C no registra por su cuenta esta propiedad, por lo que es algo a definir manualmente durante el diseño de las funciones.

### Copias independientes:

Asúmase el siguiente código:

```
int x = 10;
int y = x;

y = 30;
```

Tras ejecutarlo:

```
x = 10
y = 30
```

Aquí, `y` recibe una copia del contenido de `x`, pero los dos objetos son completamente independientes entre sí. Para modificar un objeto desde otro lugar del programa, se hace mediante su dirección; este es el propósito de los punteros.

## Punteros y Acceso Indirecto

### Punteros:

Un **puntero** es una variable cuyo valor representa una dirección de memoria. Asúmase el siguiente ejemplo:

```
int age = 21;
int *age_pointer = &age;
```

En donde:

- `age` contiene un entero (`21`).
- `*age_pointer` es de tipo `int *` y almacena la dirección de memoria de `age`.

De manera general, los punteros se definen en el siguiente esquema:

```
age_pointer   // dirección almacenada: apunta a age
*age_pointer  // valor situado en esa dirección: 21
&age          // dirección de memoria de age
```

Por lo tanto:

```
age_pointer == &age       // verdadero
*age_pointer == age       // verdadero
```

Tal y como se describe al final del capítulo anterior (y tomando como base los diagramas anteriores), es posible modificar el objeto mediante su puntero, al representar a la misma entidad:

```
*age_pointer = 30;

printf("%d\n", age);  // imprime 30
```

En donde la declaración `int *age_pointer;` se interpreta como:

	`age_pointer` es una variable que apunta a un objeto de tipo int.

En este caso, el operador `*` cumple con dos funciones distintas según el contexto:

```
int *age_pointer;   // en una declaración: indica que es un puntero
*age_pointer = 30;  // en una expresión: accede al objeto apuntado
```

### Punteros nulos:

No todos los punteros señalan a objetos válidos. Esto puede expresarse mediante un puntero con valor `NULL`:

```
int *pointer = NULL;
```

Un puntero nulo resulta de utilidad para representar estados como los siguientes:

- No existe un resultado.
- La estructura está vacía.
- La reserva de memoria falló.
- Aun no se selecciona un objeto a apuntar.
- Un enlace no conduce a otro nodo.

Sin embargo, estos no pueden ser desreferenciados:

```
int *pointer = NULL;
printf("%d\n", *pointer);
```

En este ejemplo, la expresión intenta acceder a un objeto inexistente, siendo el resultado un comportamiento indefinido.

### Punteros sin inicializar:

Ahora bien, existe una diferencia muy marcada entre un puntero nulo y uno que no ha sido inicializado; es decir:

```
int *pointer = NULL;
```

y

```
int *pointer;
```

En el primer caso, se sabe que `pointer` no señala a ningún objeto. En el segundo, el valor del puntero está indeterminado, por lo que alojará cualquier patrón de bits que hubiera estado previamente en esa región particular de la memoria, por lo que tratar de asignarle cualquier valor sería imposible al estar tratando de escribir sobre una ubicación desconocida.

	Todo puntero debe inicializarse al momento de su declaración.

Esto puede ser asignándole una dirección válida:

```
int value = 0;
int *pointer = &value;
```

O mediante `NULL`:

```
int *pointer = NULL;
```
