## Variables, Objetos y Memoria

### Variables:

Una declaración de tipo:

```
int age = 21;
```

Crea un objeto de tipo `int` con las siguientes propiedades:

```
Nombre:             age
Tipo:               int
Valor actual:       21
Tamaño:             sizeof(int)
Dirección:          una ubicación en memoria
Duración:           depende de dónde fue declarado
```

En donde:

- `age` es el nombre de la variable.
- `21` es el valor que se guarda en ese espacio de memoria.
- `int` indica cómo interpretar los bytes que conforman el contenido.

Así bien, se tiene una dirección que indica la ubicación del objeto declarado en la memoria; puede observarse mediante el operador `&`.

```
#include <stdio.h>

int main(void)
{
    int age = 21;

    printf("Valor: %d\n", age);
    printf("Direccion: %p\n", (void *)&age);

    return 0;
}
```

Mostrando como salida:

```
Valor: 21
Direccion: 0x7ffd2e6c82ac
```

Esta dirección muy seguramente variará de acuerdo con la ejecución, por lo que nunca debe asumirse que un objeto se mantendrá siempre en la misma posición.

Cabe destacar que el uso de `void *` se utiliza con `%p` de manera intencional.

### Objetos y bytes:

La memoria funge a manera de secuencia de posiciones numeradas, cada una pudiendo almacenar una pequeña cantidad de información (normalmente un solo byte).

En el caso de una variable de tipo `int`, suelen necesitarse varios bytes consecutivos (no siempre solo cuatro):

```
Dirección hipotética

0x1000   0x1001   0x1002   0x1003
+------+ +------+ +------+ +------+
| byte | | byte | | byte | | byte |
+------+ +------+ +------+ +------+
       objeto de tipo int
```

Y su tamaño suele ser fácilmente consultado mediante el método `sizeof`:

```
#include <stdio.h>

int main(void)
{
    printf("char:   %zu byte(s)\n", sizeof(char));
    printf("int:    %zu byte(s)\n", sizeof(int));
    printf("double: %zu byte(s)\n", sizeof(double));

    return 0;
}
```

En el caso de una entrevista técnica, se prefiere razonar desde una perspectiva basada en `sizeof(int)` en lugar del simple número.

### Modelo Stack y Heap:

Para comprender correctamente el funcionamiento de C, con regularidad se utiliza una división conceptual entre dos regiones distintas, tal y como se muestra en el diagrama a continuación:

```
+----------------------------------+
| Código y datos del programa      |
+----------------------------------+
| Variables globales y estáticas   |
+----------------------------------+
|                                  |
| Heap                             |
| Memoria reservada dinámicamente  |
|                                  |
+----------------------------------+
|                                  |
| Espacio disponible               |
|                                  |
+----------------------------------+
| Stack                            |
| Variables locales y llamadas     |
|                                  |
+----------------------------------+
```

Aquí se observa cómo el **stack** suele verse relacionado con:

- Variables locales.
- Parámetros de funciones.
- Información necesaria para regresar de una llamada.
- Duración automática.

Mientras que el **heap**:

- Memoria solicitada durante el tiempo de ejecución.
- Objetos cuya duración no depende directamente de una función.
- Memoria obtenida con `malloc`, `calloc` p `realloc`.
- Memoria que debe liberarse explícitamente con `free`.

### Duración automática:

Asúmase la función:

```
void example(void)
{
    int number = 10;
}
```

Aquí, el objeto `number` existe siempre y cuando el bloque se mantenga en ejecución. Su tiempo de vida termina al mismo tiempo que la del bloque en cuestión. Al ocurrir esto, cualquier puntero que tratara de mantenerse accediendo a él, deja de señalar a un objeto válido. Por ejemplo, en el caso del siguiente programa incorrecto:

```
int *create_number(void)
{
    int number = 42;
    return &number;
}
```

La función devuelve una variable local `number`; sin embargo, al esta dejar de existir al finalizar la función, el puntero recibido queda colgando:

```
Durante la función:

pointer -----> number: 42

Después de que termina:

pointer -----> región que ya no contiene un objeto válido
```

A esto se le conoce como un comportamiento indefinido.

### Duración dinámica:

Cuando se requiere que un objeto permanezca activo incluso tras la finalización de su función de origen, es posible reservar memoria de manera dinámica:

```
#include <stdlib.h>

int *create_number(void)
{
    int *number = malloc(sizeof *number);

    if (number == NULL) {
        return NULL;
    }

    *number = 42;
    return number;
}
```

Aquí, el entero deja de ser una variable local ordinaria. Si bien, el puntero local `number` sí deja de existir al finalizar la función, el bloque dinámico permanece reservado. 

Debido a la permanencia asignada a la variable en memoria, el desarrollador se hace responsable de liberarla:

```
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *number = create_number();

    if (number == NULL) {
        fprintf(stderr, "No fue posible crear el numero.\n");
        return 1;
    }

    printf("%d\n", *number);

    free(number);
    number = NULL;

    return 0;
}
```

Este es un principio al que se le conoce como **propiedad de memoria**:

	Quien recibe la propiedad de un bloque dinámico debe asegurarse de
	liberarlo cuando deje de necesitarlo.

C no registra por su cuenta esta propiedad, por lo que es algo a definir manualmente durante el diseño de las funciones.

### Copias independientes:

Asúmase el siguiente código:

```
int x = 10;
int y = x;

y = 30;
```

Tras ejecutarlo:

```
x = 10
y = 30
```

Aquí, `y` recibe una copia del contenido de `x`, pero los dos objetos son completamente independientes entre sí. Para modificar un objeto desde otro lugar del programa, se hace mediante su dirección; este es el propósito de los punteros.

## Punteros y Acceso Indirecto

### Punteros:

Un **puntero** es una variable cuyo valor representa una dirección de memoria. Asúmase el siguiente ejemplo:

```
int age = 21;
int *age_pointer = &age;
```

En donde:

- `age` contiene un entero (`21`).
- `*age_pointer` es de tipo `int *` y almacena la dirección de memoria de `age`.

De manera general, los punteros se definen en el siguiente esquema:

```
age_pointer   // dirección almacenada: apunta a age
*age_pointer  // valor situado en esa dirección: 21
&age          // dirección de memoria de age
```

Por lo tanto:

```
age_pointer == &age       // verdadero
*age_pointer == age       // verdadero
```

Tal y como se describe al final del capítulo anterior (y tomando como base los diagramas anteriores), es posible modificar el objeto mediante su puntero, al representar a la misma entidad:

```
*age_pointer = 30;

printf("%d\n", age);  // imprime 30
```

En donde la declaración `int *age_pointer;` se interpreta como:

	`age_pointer` es una variable que apunta a un objeto de tipo int.

En este caso, el operador `*` cumple con dos funciones distintas según el contexto:

```
int *age_pointer;   // en una declaración: indica que es un puntero
*age_pointer = 30;  // en una expresión: accede al objeto apuntado
```

### Punteros nulos:

No todos los punteros señalan a objetos válidos. Esto puede expresarse mediante un puntero con valor `NULL`:

```
int *pointer = NULL;
```

Un puntero nulo resulta de utilidad para representar estados como los siguientes:

- No existe un resultado.
- La estructura está vacía.
- La reserva de memoria falló.
- Aun no se selecciona un objeto a apuntar.
- Un enlace no conduce a otro nodo.

Sin embargo, estos no pueden ser desreferenciados:

```
int *pointer = NULL;
printf("%d\n", *pointer);
```

En este ejemplo, la expresión intenta acceder a un objeto inexistente, siendo el resultado un comportamiento indefinido.

### Punteros sin inicializar:

Ahora bien, existe una diferencia muy marcada entre un puntero nulo y uno que no ha sido inicializado; es decir:

```
int *pointer = NULL;
```

y

```
int *pointer;
```

En el primer caso, se sabe que `pointer` no señala a ningún objeto. En el segundo, el valor del puntero está indeterminado, por lo que alojará cualquier patrón de bits que hubiera estado previamente en esa región particular de la memoria, por lo que tratar de asignarle cualquier valor sería imposible al estar tratando de escribir sobre una ubicación desconocida.

	Todo puntero debe inicializarse al momento de su declaración.

Esto puede ser asignándole una dirección válida:

```
int value = 0;
int *pointer = &value;
```

O mediante `NULL`:

```
int *pointer = NULL;
```

### Tipos de puntero:

A lo largo de los segmentos anteriores, se ha hecho uso de punteros de los siguientes tipos:

```
int *
double *
char *
```

Esto se debe a que el compilador debe tener conocimiento acerca de qué clase de objeto espera encontrar dentro de esa dirección. Asúmase `int *integer_pointer`; en este ejemplo, se indica que la dirección debería conducir a un elemento de tipo entero. De esta manera, el compilador puede elegir:

- Cuántos bytes leer al llevar a cabo el proceso de desreferenciación.
- Cómo interpretar los bytes leídos.
- Cuántos bytes escribir.
- Cuánto avanzar al realizar aritmética de punteros. 

Por ejemplo, la expresión:

```
integer_pointer + 1
```

No le indica al programa que avance un solo byte, sino que avance hacia la posición del siguiente valor de tipo `int` con el que se encuentre.

### Punteros y constantes:

Asúmase un caso en el que una función debe leer un entero, mas no modificarlo:

```
void print_number(const int *number)
{
    if (number == NULL) {
        return;
    }

    printf("%d\n", *number);
}
```

Para ello, la declaración `const int *number`, indica que la función no debe ser capaz de modificar el entero a través del puntero. La utilización de constantes mejora los contratos de las funciones, comunicando de manera implícita las operaciones permitidas mediante el propio compilador.

Ahora bien, existe una diferencia muy clara entre sentencias de tipo:

```
const int *pointer;
```

El dato no puede modificarse mediante el puntero.

```
int *const pointer = &value
```

El puntero no puede cambiar para señalar a otro objeto.

```
const int *const pointer = &value;
```

Ni el dato puede modificarse usando al puntero, ni el puntero puede cambiar de dirección.

### Alias:

Existen casos particulares en los que dos punteros pueden señalar hacia un mismo objeto. En caso de ocurrir, a estos se les pasa a conocer como **alias**:

```
int value = 10;

int *a = &value;
int *b = &value;
```

En caso de que uno de ellos modifique el valor de la variable apuntada, el cambio se hace global para todos los punteros (excepto si el valor asignado es `NULL`). Este concepto es relevancia para análisis en errores de memoria. 

##### Ejemplo:

Estudia cuidadosamente este programa:

```
#include <stdio.h>

int main(void)
{
    int a = 5;
    int b = 8;

    int *pointer = &a;

    *pointer = 10;

    pointer = &b;
    *pointer = 20;

    printf("a = %d\n", a);
    printf("b = %d\n", b);

    return 0;
}
```

Inicialmente:

```
a = 5
b = 8
pointer = &a
```

Después de:

```
*pointer = 10;
```

tenemos:

```
a = 10
b = 8
pointer = &a
```

Después:

```
pointer = &b;
```

el puntero cambia de dirección:

```
a = 10
b = 8
pointer = &b
```

Finalmente:

```
*pointer = 20;
```

modifica `b`.

La salida es:

```
a = 10
b = 20
```

## Funciones, Paso por Valor y Punteros Dobles

Considérese la función:

```
void change(int number)
{
    number = 100;
}
```

En donde su comportamiento se ve definido en:

```
int value = 10;
change(value);
```

Tras la llamada, `value` se mantiene como `10`:

```
main                      change

value = 10                number = 10
                             |
                             v
                          number = 100
```

En este caso, modificar el valor de `number` no afecta al valor original debido a que en C, los argumentos solo se pasan por valor, mismo concepto que afecta de igual manera a los punteros. 

Cuando se dice que un argumento se _pasa por valor_, significa que la función recibe una copia del valor de la variable original. Por lo tanto, cualquier modificación realizada sobre el parámetro dentro de la función afecta únicamente a dicha copia y no altera la variable utilizada en la llamada.

### Pasar una dirección:

Para lograr modificar el valor original mediante la función, tendría que pasarse su dirección directamente:

```
#include <stdbool.h>

bool set_value(int *destination, int value)
{
    if (destination == NULL) {
        return false;
    }

    *destination = value;
    return true;
}
```

Utilizado como:

```
int score = 0;

if (!set_value(&score, 100)) {
    /* manejar error */
}
```

En este caso, la dirección es copiada al parámetro `destination`, pero ambas direcciones llevan al mismo valor entero.

```
score
+------+
|  0   |
+------+
   ^
   |
destination
```

Llevándose a cabo la modificación tras ejecutar `*destination = value;`.

### Intercambio de dos valores

Este es un ejercicio de suma utilidad al obligar a distinguir la diferencia entre valores y direcciones. Asúmase el caso incorrecto:

```
void swap(int a, int b)
{
    int temporary = a;
    a = b;
    b = temporary;
}
```

Aquí, solo se intercambian las copias locales; la función intercambia esas copias, pero al terminar su ejecución se destruyen y los valores originales permanecen iguales. Por otro lado, una versión correcta estaría recibiendo direcciones:

```
#include <stdbool.h>

bool swap_ints(int *a, int *b)
{
    if (a == NULL || b == NULL) {
        return false;
    }

    int temporary = *a;
    *a = *b;
    *b = temporary;

    return true;
}
```

Implementado en:

```
#include <stdio.h>

int main(void)
{
    int first = 10;
    int second = 20;

    if (!swap_ints(&first, &second)) {
        return 1;
    }

    printf("%d %d\n", first, second);
    return 0;
}
```

Considérese que el uso del operador `!` permite la negación lógica. En este caso, es útil dado que es útil dado que invierte el valor retornado por la función `swap_ints`. Si dicha función devuelve `0`, indicando que el intercambio no se realizó correctamente, el operador `!` convierte ese valor en verdadero y se ejecuta el bloque del `if`, finalizando el programa con el código de error `1`. En cambio, si la función devuelve un valor distinto de `0`, la condición resulta falsa y el programa continúa hasta imprimir los valores intercambiados.

### Modificación del contenido señalado:

Asúmase:

```
int value = 10;
int *pointer = &value;
```

Con una función:

```
void change_value(int *pointer)
```

Es capaz de modificar `value` a través de:

```
*pointer = 50;
```

Sin embargo, si se tratase de cambiar la dirección a la que apunta; es decir:

```
void redirect(int *pointer)
{
    pointer = NULL;
}
```

El puntero original no cambia al solo haber pasado por valor. Solo cambia la copia local.

```
Llamador                  Función

pointer = &value          copia = &value
                          copia = NULL
```

### Dirección de un puntero:

Para modificar el puntero, se sigue la misma filosofía que para las variables: debe hacerse mediante su dirección. Si `int *pointer;` es un puntero hacia `int`, entonces `&pointer` sería la dirección de un puntero a entero. En este caso, surge:

```
int **
```

Es un puntero a puntero entero.

##### Ejemplo:

Téngase en cuenta:

```
#include <stdbool.h>

bool set_null(int **pointer)
{
    if (pointer == NULL) {
        return false;
    }

    *pointer = NULL;
    return true;
}
```

Llamado en:

```
int value = 10;
int *number = &value;

set_null(&number);
```

Inicialmente, `number` es el puntero que contiene la dirección de `value`:

```
&number
   |
   v
+------------+
| number     | --------> value
+------------+
```

Por su parte, `&number` obtiene la dirección de memoria de la propia `number`; es decir, el argumento enviado a `set_null` es de tipo `int **`: un puntero a otro puntero. De manera particular, `pointer` contiene la dirección de `number` y `*pointer` el valor de esta. Por lo tanto, al ejecutar:

```
*pointer = NULL;
```

esto no modifica solo la copia local, sino que se accede hasta la variable `number`, cambiándose el valor que esta misma almacena; es decir, deja de apuntar a `value` y pasa a ser un puntero nulo.

Un dato a destacar, es que las listas utilizan punteros dobles para ubicar la ubicación de `head`.
