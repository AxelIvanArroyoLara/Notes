## Introducción

El bloque de aprendizaje actual tiene el objetivo de construir las bases necesarias para comprender conceptos como listas, árboles, grafos, tablas de hash y otras estructuras.

Como objetivos principales se plantea determinar:

- La localización de una variable.
- Qué guardan los punteros.
- Quién se responsabiliza de liberar cada bloque de memoria.
- Qué ocurre cuando una función termina.
- Por qué aparecen los `segmentation faults`.
- Detectar fugas de memoria y accesos inválidos.

## Modelo Mental de Memoria

En este segmento se desea lograr la distinción entre una variable y propiedades como su valor, dirección y tiempo de vida, así como distinguir la memoria automática de la dinámica.

Durante el curso se utilizará el siguiente modelo conceptual: 

```
+---------------------------+
| Código del programa       |
+---------------------------+
| Datos globales/estáticos  |
+---------------------------+
| Heap                      |
| memoria dinámica          |
| malloc / calloc / realloc |
+---------------------------+
|                           |
|                           |
+---------------------------+
| Stack                     |
| variables locales         |
| llamadas a funciones      |
+---------------------------+
```

Este modelo es una simplificación explicativa: C no obliga a la implementación con *stack* y *heap*, pero ese es el modelo más utilizado en sistemas y compiladores.

### Variables locales:

```
#include <stdio.h>

int main(void)
{
    int age = 21;
    double average = 9.4;

    printf("%d\n", age);
    printf("%.1f\n", average);

    return 0;
}
```

En donde:

```
Stack de main
+---------------------+
| age       | 21      |
+---------------------+
| average   | 9.4     |
+---------------------+
```

Estas variables tienen un tiempo de vida automático; es decir, dejan de existir una vez dada la terminación del bloque o función que las contiene.

### Direcciones:

Conceptualmente, una variable contiene los siguientes parámetros:

- Nombre
- Tipo
- Valor
- Dirección
- Tamaño

En donde la dirección es dependiente de la ejecución y nunca se asume como fija.

Para ver la dirección exacta en la que se encuentra guardada una variable, puede utilizarse:

```
#include <stdio.h>

int main(void)
{
    int age = 21;

    printf("Valor: %d\n", age);
    printf("Direccion: %p\n", (void *)&age);

    return 0;
}
```

En donde:

- `&age` indica "la dirección de `age`".
- `%p` espera un `void *`, lo que convierte la dirección al imprimirla.

En este caso, es importante recordar que un **puntero** se define como una variable que almacena una dirección, siendo `*` el operador utilizado para acceder al objeto señalado.

##### Ejemplo:

Considérese: 

```
int x = 10;
int y = x;

y = 20;
```

Cuyo resultado es:

```
x = 10
y = 20
```

En donde `y` recibió una copia del valor almacenado en `x`, pero no quedó conectada a este último.

Para que `y` tuviera la capacidad de modificar directamente a `x`, se tendría que guardar en este primero la dirección de la variable mencionada.

## Punteros y acceso indirecto

### Punteros:

Un **puntero** se define como una variable cuyo valor representa una dirección de memoria. En el ejemplo:

```
int age = 21;
int *age_pointer = &age;
```

se representan dos objetos diferentes. El primero contiene un número entero (`age = 21`):

```
age
+------+
| 21   |
+------+
```

mientras que el segundo contiene la dirección de ese entero:

```
age_pointer
+----------------+
| dirección age  |
+----------------+
        |
        v
      +------+
age   | 21   |
      +------+
```

En la declaración:

```
int *age_pointer;
```

se lee como:

	`age_pointer` es un puntero a un valor `int`.

Es decir, puede almacenar la dirección de un objeto de este tipo.

### Operador de dirección:

Por su parte, el operador `&` obtiene la dirección de un objeto:

```
int value = 15;
int *pointer = &value;
```

En donde:

- `value` representa el contenido del entero.
- `&value` representa su dirección.

Pueden imprimirse ambas cosas:

```
#include <stdio.h>

int main(void)
{
    int value = 15;
    int *pointer = &value;

    printf("Valor de value: %d\n", value);
    printf("Direccion de value: %p\n", (void *)&value);
    printf("Contenido de pointer: %p\n", (void *)pointer);

    return 0;
}
```

Resultado:

```
Valor de value: 15
Dirección de value: 0x123
Contenido de pointer: 0x123
```

El `pointer` y `&value` representan la misma dirección.

### Operador de desreferenciación:

Una vez que se tiene una dirección, se necesita una manera de acceder al objeto ubicado en ese lugar. 

Para ello se utiliza el operador `*`:

```
printf("%d\n", *pointer);
```

En donde la expresión `*pointer` puede leerse como:

	El objeto señalado por `pointer`

En caso de que `pointer` señale a `value`, entonces `*pointer` y `value` se refieren al mismo objeto. Es por este motivo que se puede efectuar la modificación indirecta:

```
int value = 15;
int *pointer = &value;

*pointer = 80;
```

Al terminar:

```
value = 80
```

No se cambia el contenido del puntero, sino que este permanece guardando la misma dirección; lo que se modifica fue el objeto guardado en dicho lugar.

### Los dos significados de `*`:

El asterisco aparece en dos contextos diferentes.

En una declaración:

```
int *pointer;
```

En donde se indica que `pointer` es una variable de tipo puntero a entero.

En una expresión:

```
*pointer = 20;
```

Que accede al objeto señalado. 

### Punteros nulos: 

Ahora bien, no todos los punteros señalan necesariamente a un objeto válido, sino que puede indicarse explícitamente que un puntero no señala a ningún objeto a mediante `NULL`:

```
int *pointer = NULL;
```

En este caso, un puntero nulo puede ser utilizado para representar cualquiera de los siguientes estados:

- No existe un resultado.
- La estructura está vacía.
- La reserva de memoria falló.
- Todavía no se ha elegido un objeto.
- Un enlace no conduce a otro nodo.

Lo que puede hacerse es efectuar una desreferenciación:

```
int *pointer = NULL;
printf("%d\n", *pointer);
```

Aquí, la expresión `*pointer` intenta acceder a un objeto inexistente, lo que resulta en un comportamiento indefinido. El manejo correcto sería:

```
if (pointer != NULL) {
    printf("%d\n", *pointer);
}
```

### Punteros sin inicializar:

Ahora bien, existe una gran diferencia entre la declaración de un puntero nulo y no asignarle ningún valor:

```
int *pointer;
```

En el primer caso, se sabe que `pointer` no señala a ningún objeto, mientras que en el segundo su valor es indeterminado. Aquí se podría contener cualquier patrón de bits que estuviera en esa región de la memoria; es decir, basura. Por lo tanto, el siguiente código es incorrecto:

```
int *pointer;
*pointer = 50;
```

Aquí no se creó ningún entero ni se asignó a una dirección válida, sino que se está intentando escribir en una ubicación desconocida.

La regla segura para comenzar con punteros es siempre inicializarlos al momento de declararlos:

```
int value = 0;
int *pointer = &value;
```

o

```
int *pointer = NULL;
```
