## Introducción

Los modelos de Machine Learning funcionan internamente con base en estructuras matemáticas complejas. El objetivo del presente módulo se encuentra en comprender la representación de datos a través de estructuras como vectores, matrices y tensores, así como los mecanismos de operación para la estructuras y la manera en la que aparecerá el gradiente como mecanismo para entrenar modelos.

---

## Objetos Matemáticos

En el Machine Learning se trabaja con cosas del mundo real:

- personas;
- películas;
- imágenes;
- documentos;
- sensores;
- productos.

Sin embargo, un algoritmo no entiende directamente conceptos como el género de una película; debe convertirse esa información a números. Por ejemplo, esta misma película puede ser representada utilizando cuatro características:

$$x= \begin{bmatrix} 5\\ 0\\ 5\\ 2 \end{bmatrix}$$

En donde cada posición significa:

1. Acción.
2. Comedia.
3. Ciencia ficción.
4. Drama.

A este conjunto ordenado de números a su vez, se le conoce como *vector*. 

### Vectores:

Un vector es representado formalmente por:

$$v\in \mathbb{R}^n$$
Que representa una serie ordenada de números $n$:

$$v=(v_1,v_2,...,v_n)$$
En donde cada componente puede representar un *feature* distinto:

$$x= \begin{bmatrix} 8\\ 90\\ 7.8 \end{bmatrix}$$

Asumiendo esto como el caso de un estudiante, los valores pueden representar:

- $8$ horas de estudio.
- $90$ porciento de asistencia.
- $7.8$ de promedio previo.

En donde el vector completo representa una sola observación.

### Matrices:

Una **matriz** tiene el propósito de agrupar una serie de múltiples vectores:

$$A\in \mathbb{R}^{n\times m}$$
En donde:

- $n$ representa las filas.
- $m$ es el número de columnas.

Asúmase una matriz $X$ para representar un dataset completo:


$$ X= \begin{bmatrix} 1.2 & 3.1 & 0.5\\ 0.9 & 2.7 & 1.4\\ 2.2 & 0.4 & 3.3 \end{bmatrix} $$

Aquí las filas representan *observaciones* y las columnas las *features*.

#### Shape en NumPy

En programación, haciendo uso de la librería NumPy, se `shape` para conocer las dimensiones de los datos:

```
X.shape
```

Devuelve:

```
(1000, 20)
```

Se tienen 1000 muestras y 20 features.

Esta operación resulta de suma importancia dado que ciertas ecuaciones solo pueden llevarse acabo dada una dimensionalidad compatible entre ambas matrices.

#### Matrices en NumPy

Una matriz puede representarse en NumPy haciendo uso de:

```
import numpy as np

X = np.array([
    [1.2, 3.1, 0.5],
    [0.9, 2.7, 1.4],
    [2.2, 0.4, 3.3]
])
```

Obteniendo la forma con:

```
X.shape
```
Así bien, `X[0,:]` selecciona la primera fila, mientras que `X[:,0]` selecciona la primera columna. De manera conceptual:

```
X[0, :]
→ primera observación

X[:, 0]
→ primera feature de todas las observaciones
```

### DataFrames con Pandas:

A pesar de que NumPy tiene la capacidad de representar estructuras matemáticas directamente, en datasets suele utilizarse Pandas dado que permite añadir los nombres de las columnas a las matrices, facilitando la manipulación de las mismas:

```
import pandas as pd

X = pd.DataFrame([
    [1.2, 3.1, 0.5],
    [0.9, 2.7, 1.4],
    [2.2, 0.4, 3.3]
], columns=[
    "feature_1",
    "feature_2",
    "feature_3"
])
```

Pudiendo acceder a las features directamente por su nombre:

```
X["feature_1"]
```

## Operaciones Fundamentales con Vectores

Una vez que se logra la representación de los datos mediante vectores, se debe poder trabajar con ellos. Con este fin, se llevan a cabo operaciones tales como:

- Suma.
- Multiplicación por escalar.
- Norma.
- Normalización.
- Producto punto.

### Suma de vectores:

Asúmase un vector $u$:

$$u=(1,2), \space v=(3,4)$$
Entonces:

$$u+v=(4,6)$$
### Multiplicación por escalar:

Un **escalar** se define como un número individual en lugar de una estructura completa. Realizando la operación con:

$$v=(1,2)$$
$$2v=(2,4)$$
En donde cada componente se multiplica por la constante escalar.

### Norma de un vector:

La **norma** es una propiedad que mide la longitud de un vector. Esta es representada a través de la expresión:

$$||v||$$
Que por norma euclidiana:

$$ \|v\|= \sqrt{\sum_i v_i^2} $$
Asumiendo que:

$$v=(3,4)$$

Se obtiene:

$$\|v\| = \sqrt{3^2+4^2} = \sqrt{9+16} = 5$$

De manera geométrica, esto representa la distancia entre el origen hasta el punto representado por el vector.

### Normalización:

Es posible convertir un vector en otro que conserve su dirección pero que tan solo tenga una longitud $1$. 

Para:

$$u=(3,4)$$
Se sabe que:

$$||u||=5$$
Entonces el vector normalizado:

$$\hat{u}=\frac{u}{||u||} \rightarrow \hat{u}=(\frac{3}{5}, \frac{3}{5})$$
Obteniendo como resultado:

$$\hat u={(0.6,0.8)}$$
En donde:

$$||\hat u||=1$$
Este proceso de normalización permite comparar direcciones sin que la magnitud afecte la operación.

### Producto punto:

Asumiendo un producto punto entre:

$$ u=(u_1,u_2,\ldots,u_n) $$

y:

$$ v=(v_1,v_2,\ldots,v_n) $$

Se obtiene:

$$u\cdot v = \sum_i u_iv_i$$
Por ejemplo:

$$ (1,2)\cdot(3,4) $$

$$(1)(3)+(2)(4) $$

$$3+8 =11 $$

El resultado es **un escalar**.

Esta misma operación aparece en:

- neuronas;
- regresión;
- sistemas de recomendación;
- similitud;
- transformaciones lineales.

### Producto punto y ángulo:

El producto punto también contiene información sobre el **ángulo entre dos vectores**.

La relación es:

$$\cos\theta = \frac{u\cdot v} {\|u\|\|v\|} $$
Esto permite comparar sus direcciones.

Si:

$$ \cos\theta\approx1 $$

los vectores apuntan prácticamente hacia la misma dirección.

Si:

$$ \cos\theta\approx0 $$

son aproximadamente perpendiculares.

Si:

$$ \cos\theta<0 $$

apuntan en direcciones opuestas.

### Similitud coseno:

Conocida como **cosine similarity**, esta operación es bastante utilizada dentro del campo de estudio del Machine Learning. 

Dos documentos pueden ser representados haciendo uso de vectores. Si estos contienen palabras similares en proporciones similares:

$$cos \theta \approx 1$$
Se pueden interpretar como documentos similares.

Por otro lado, si no comparten características:

$$cos \theta \approx 0$$
Ahora bien, la diferencia frente a la distancia euclidiana resulta de suma importancia, ya que la similitud coseno toma en cuenta la dirección, no la magnitud.

###### Ejemplo:

Supóngase las siguientes películas:

| Película     | Action | Comedy | Sci-Fi | Drama |
| ------------ | ------ | ------ | ------ | ----- |
| The Matrix   | 5      | 0      | 5      | 2     |
| John Wick    | 5      | 0      | 0      | 2     |
| Toy Story    | 1      | 5      | 1      | 2     |
| Interstellar | 1      | 0      | 5      | 5     |
| The Notebook | 0      | 1      | 0      | 5     |

Y el usuario tiene preferencias:

$$ u= \begin{bmatrix} 5\\ 1\\ 5\\ 2 \end{bmatrix} $$

Esto significa que le gustan especialmente:

- acción;
- ciencia ficción.

Cada película es un vector

Por ejemplo:

$$ x_{\text{Matrix}}= \begin{bmatrix} 5\\ 0\\ 5\\ 2 \end{bmatrix} $$

Podemos comparar la película con las preferencias del usuario mediante:

$$ x^Tu $$

Para _The Matrix_:

$$ 5(5)+0(1)+5(5)+2(2) $$$$ =25+0+25+4 $$$$ =54 $$

Ese número se utiliza como **score de afinidad**.

 Todas las películas como una matriz.

En lugar de calcular película por película:

$$ X= \begin{bmatrix} 5&0&5&2\\ 5&0&0&2\\ 1&5&1&2\\ 1&0&5&5\\ 0&1&0&5 \end{bmatrix} $$
y:

$$ u= \begin{bmatrix} 5\\ 1\\ 5\\ 2 \end{bmatrix} $$

podemos calcular:

$$ s=Xu $$

obteniendo:

$$ s= \begin{bmatrix} 54\\ 29\\ 19\\ 40\\ 11 \end{bmatrix} $$

Por lo tanto:

```
The Matrix   → 54
Interstellar → 40
John Wick    → 29
Toy Story    → 19
The Notebook → 11
```

El sistema recomendaría **The Matrix**.

La idea importante es:

> Una sola multiplicación matriz-vector calculó todos los productos punto simultáneamente.

### Multiplicación matriz - vector:

Si:

$$ A\in\mathbb{R}^{n\times m} $$

y:

$$ x\in\mathbb{R}^{m} $$

entonces:

$$ Ax\in\mathbb{R}^{n} $$

Las dimensiones internas deben coincidir:

```
(n × m)(m)
       ↑
     coincide
```

El resultado tiene $n$ elementos.

Ejemplo:

$$ A= \begin{bmatrix} 1&2\\ 0&-1\\ 3&1 \end{bmatrix} $$

y:

$$ x= \begin{bmatrix} 2\\ -1 \end{bmatrix} $$

Entonces:

$$ Ax= \begin{bmatrix} 1(2)+2(-1)\\ 0(2)+(-1)(-1)\\ 3(2)+1(-1) \end{bmatrix} = \begin{bmatrix} 0\\ 1\\ 5 \end{bmatrix} $$

### Multiplicación matriz - matriz:

Si:

$$ A\in\mathbb{R}^{n\times m} $$

y:

$$ B\in\mathbb{R}^{m\times p} $$

entonces:

$$ AB\in\mathbb{R}^{n\times p} $$

La regla práctica es:

$$ (n\times m)(m\times p) \rightarrow (n\times p) $$

Las dimensiones internas:

$$ m $$

deben coincidir.

Esto es importantísimo para entender redes neuronales, porque gran parte de sus cálculos son precisamente multiplicaciones de matrices.

## Operador `@` en NumPy

NumPy utiliza:

```
@
```

para multiplicación matricial.

Por ejemplo:

```
Ax = A @ x
```

o:

```
AB = A @ B
```

También:

```
u @ v
```

produce un producto punto cuando `u` y `v` son vectores.

NumPy puede representar estructuras de diferentes dimensiones.

### Escalar — 0D:

```
np.array(7)
```

Shape:

```
()
```

### Vector — 1D:

```

```

Shape:

```
(3,)
```

### Matriz — 2D:

```
np.array([
```

## Imágenes como Números

Cuando un ser humano observa una imagen, puede discernir entre:

- Formas.
- Objetos.
- Colores.
- Personas.
- Dígitos.

Sin embargo, un sistema computacional solo es capaz de recibir números organizados dentro de una estructura de datos.

### Imagen en escala de grises:

Una imagen en **grayscale** puede ser representada mediante la expresión:

$$P\in\mathbb{R}^{H\times W}$$

En donde:

- $H$ representa la altura.
- $W$ es el ancho.

En donde cada posición contiene la intensidad de un píxel.

De manera general, los valores pequeños representan un píxel oscuro, mientras que los grandes denotan un píxel brillante:

$$ P= \begin{bmatrix} 0&0&16&0&0\\ 0&16&16&0&0\\ 0&0&16&0&0\\ 0&0&16&0&0\\ 0&16&16&16&0 \end{bmatrix} $$

La computadora recibe esa matriz, no el concepto de imagen.

### Shape de una imagen:

Una imagen grayscale de:

$$ 224\times224 $$

tiene shape:

```
(224, 224)
```

porque solamente se necesita:

```
altura × ancho
```

Cada pixel almacena una única intensidad.

### Imágenes a vectores:

Algunos algoritmos esperan de forma predeterminada que una observación sea representada a través de un vector. Por lo tanto, es posible tomar una imagen:

$$ P\in\mathbb{R}^{8\times8} $$

y aplicar:

```
flatten
```

para obtener:

$$x\in\mathbb{R}^{64} $$

porque:

$$ 8\times8=64 $$

Conceptualmente:

```
Imagen 8×8
   ↓ flatten
Vector con 64 componentes
```

Cada pixel se convierte en una feature.

Ahora, si se tiene una cantidad $N$ de imágenes, cada una conteniendo 64 píxeles:

$$ X\in\mathbb{R}^{N\times64} $$

Por ejemplo:

```
1000 imágenes 8×8
```

se convierten en:

$$ X\in\mathbb{R}^{1000\times64} $$

Cada fila:

> una imagen.

Cada columna:

> un pixel/feature.

### El problema de flatten:

Flatten resulta útil para modelos clásicos, pero destruye explícitamente la estructura bidimensional.

Originalmente:

```
pixel arriba
pixel abajo
pixel izquierda
pixel derecha
```

tienen una relación espacial clara.

Después de aplanar:

```
x1, x2, x3, ..., x64
```

esa estructura espacial deja de estar representada directamente.

Esta es una de las razones por las que modelos especializados en imágenes, como las CNN, trabajan con representaciones multidimensionales.
### Imágenes RGB como tensores:

Una imagen RGB no almacena un único valor por pixel.

Cada pixel contiene tres componentes:

- rojo \(R\);
- verde \(G\);
- azul \(B\).

Cada canal individual es una matriz:

$$ R\in\mathbb{R}^{H\times W} $$$$ $$$$ G\in\mathbb{R}^{H\times W} $$$$ B\in\mathbb{R}^{H\times W} $$

Los tres canales se **apilan**:

$$ T\in\mathbb{R}^{H\times W\times3} $$

Por ejemplo:

```
(224, 224, 3)
```

Es importante que los canales **no se suman**, sino que se almacenan en una dimensión adicional.

### Batch:

Un **batch** es un conjunto de observaciones procesadas juntas.

Las formas quedan así:

| Datos                  | Shape         |
| ---------------------- | ------------- |
| Imagen grayscale       | $$(H,W)$$     |
| Imagen RGB             | $$(H,W,3)$$   |
| $N$ imágenes grayscale | $$(N,H,W)$$   |
| $N$ imágenes RGB       | $$(N,H,W,3)$$ |

Por ejemplo, 32 imágenes RGB de:

$$ 224\times224 $$

forman:

$$ T\in\mathbb{R}^{32\times224\times224\times3} $$

Aquí:

```
32  → cantidad de imágenes
224 → altura
224 → ancho
3   → canales RGB
```
###### Ejemplo:

La pregunta planteada es:

> ¿Cuál es el shape de 100 imágenes grayscale de $28\times28$?

Tenemos:

```
N = 100
H = 28
W = 28
```

Entonces:

$$(100,28,28)$$ 

Es un tensor de tres dimensiones.
